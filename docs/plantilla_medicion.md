# Plantilla de medición operativa

Esta plantilla sirve para comparar el proceso anterior con el proceso apoyado
por la herramienta. Debe llenarse con observaciones reales y bajo un criterio
constante. No deben completarse celdas con estimaciones no verificadas.

## Resumen comparativo

| Indicador | Proceso anterior | Con herramienta | Fórmula / criterio |
|---|---:|---:|---|
| Tiempo promedio de localización | | | Promedio de tiempos observados |
| Tiempo promedio de registro | | | Promedio de tiempos observados |
| Pasos manuales promedio | | | Promedio de pasos contados |
| Errores o correcciones | | | Conteo en la muestra |
| Registros completos | | | Registros completos / registros revisados × 100 |
| Operaciones trazables | | | Operaciones trazables / operaciones revisadas × 100 |

## Reglas para comparar

1. Definir previamente la operación y el tamaño de la muestra.
2. Usar el mismo criterio de inicio y fin en ambas modalidades.
3. Registrar quién realizó la operación y cuándo se observó.
4. No comparar muestras con alcances diferentes.
5. Conservar los registros originales que respalden los promedios.

Cuando exista una medición válida, la reducción porcentual podrá calcularse como:

```text
(valor anterior - valor posterior) / valor anterior × 100
```

Hasta contar con esos registros, el sistema sólo debe reportar indicadores
operativos derivados de sus propios datos.
